An end-to-end grounded conversational voice agent for **ZentroMart**, built for the **VoiceOps 2026 Capstone Challenge** (Consulting & Analytics Club, IIT Guwahati × Gnani.ai).

The agent handles customer support across text and voice, enforcing identity-checked order lookups, precedence-weighted policy retrieval (RAG), holiday-aware business timelines, and automated speech processing via **Gnani STT and TTS**.

---

## 🏆 Key Benchmark Scores

Evaluated on the official Capstone evaluation dataset:
- **Step 1 (Prompt-Only Baseline):** 5.8% (3 / 52 questions passed)
- **Step 2 (Document-Grounded RAG):** **100.0%** (52 / 52 questions passed, 100% retrieval hit rate) -> **+94.2% score gain**
- **Step 3 (Multi-Turn Conversations):** **100.0%** (96 / 96 turns passed across 23 conversations and 12 distinct customer scenarios)
- **Step 4 (Voice Pipeline):** End-to-end audio processing via Gnani STT and TTS with text normalization for the ear.

## 🚀 Quick Start & Installation

### 1. Prerequisites
- Python 3.10 or higher
- (Optional) Gnani API key from [app.gnani.ai/voice](https://app.gnani.ai/voice)

### 2. Install Dependencies
```bash
python -m pip install -r requirements.txt
```

### 3. Environment Configuration
Copy `.env.example` to `.env` and set your Gnani API key:
```bash
cp .env.example .env
```
In `.env`:
```env
GNANI_API_KEY=your_gnani_api_key_here
```
*(Note: If no API key is provided, the agent runs in offline simulation mode, allowing fully reproducible offline evaluation).*

## 🎙️ Running the Batch Audio Command

Per the tournament instructions, the organizers test every agent using a single command that accepts a folder of customer audio recordings and saves the text and audio replies with document chunks used:

```bash
python run.py --input-dir <path_to_customer_audio_folder> --output-dir <path_to_output_folder>
```

Or using positional arguments:
```bash
python run.py sample_inputs sample_outputs/batch_run
```

### Output Format
The output folder will contain:
- `reply_<audio_filename>.wav`: Synthesized speech audio reply generated by Gnani TTS.
- `batch_results.json`: Summary metadata with transcribed text, reply text, speech-normalized text, decision, and retrieved document section IDs.

Example output entry:
```json
{
  "input_audio": "sample_inputs/call_01_wallet_refund.wav",
  "heard": "How fast are refunds to the ZentroMart Wallet?",
  "reply_text": "Instant, within 2 hours of initiation.",
  "speech_text": "Instant, within 2 hours of initiation.",
  "output_audio": "sample_outputs/batch_run/reply_call_01_wallet_refund.wav",
  "evidence_used": ["REF-2", "KB-00.1", "PAY-4", "REF-3"],
  "decision": "answer"
}
```

## 🛡️ Architectural Principles & Safety

1. **Identity Verification Gate (`IDV-1` to `IDV-4`):**
   - Order details are strictly concealed until the caller verifies either the **last 4 digits of their registered phone** or their **delivery pincode**.
   - Verification values are never logged or spoken aloud.
2. **Precedence Hierarchy (`KB-00.1`):**
   - Current Policy > Agent Guides > Help Articles > FAQs > Marketing Pages.
   - Prevents trap failures (e.g. `FAQ-1` flat 5-7 days vs `REF-2` method-specific timelines).
3. **Calendar & Warehouse Holiday Logic (`KB-00.2`, `KB-00.3`):**
   - Reference date frozen at **20 October 2026**.
   - Monday to Saturday business days, skipping warehouse festival closures.
4. **Speech Normalization for the Ear (`STY-3`):**
   - Digits in 8-digit order numbers are spaced into groups (`"8 9 7 8  2 8 3 7"`).
   - Dates formatted as `"the 24th of October 2026"`.
   - Currency written as `"forty-nine rupees"`.
   - Replies limited to 2–3 concise sentences.
